将教师教案表改为**汽车工程系实训课程报告**，做成 **A4 纵向、正反面两页** 可填写页面，支持导出 Word（.docx）、双面打印或导出 PDF。

## 使用方法

1. 用浏览器打开 `index.html`，或按下方 Docker 部署后访问。
2. 在表格中直接填写，内容会自动保存在本机浏览器中。
3. 点击 **导出 Word**，下载与网页表格对应的 `.docx` 文件，可用 WPS 或 Microsoft Word 打开、继续填写或打印。
4. 也可点击 **打印 / 导出 PDF**。
5. 在打印对话框中：
   - 纸张：`A4`
   - 方向：`纵向`
   - 双面打印：开启，翻转方式选 `长边翻转`
   - 边距：`无`
   - 勾选 `背景图形`，以保留绿色表格线

也可点击「填写示例」查看一份动力电池包拆装与绝缘检测样例，或「清空」后打印空白表手写。

## Docker 部署

需要本机已安装 Docker 和 Docker Compose。

```bash
docker compose up -d --build
```

浏览器打开 http://localhost:5174 即可填写、导出 Word 或打印 PDF。

常用命令：

```bash
docker compose ps
docker compose logs -f
docker compose down
```

默认把容器 80 端口映射到本机 **5174**。若要改端口，编辑 `docker-compose.yml` 中的 `"5174:80"`。
