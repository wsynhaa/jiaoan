# 新能源汽车实训记录表（A3）

将教师教案表改为**新能源汽车学生实训记录表**，做成一张 **A3 横向** 可填写页面，支持打印为 PDF。面向动力电池、驱动电机、充电系统等高压实训。

## 对照说明

| 教师教案 | 新能源汽车实训记录表 |
| --- | --- |
| 课题 | 实训课题 |
| 教学目标 | 实训目标 |
| 教学重点 / 难点 | 学生版不设此项 |
| 教学方法、学生学法 | 实训方法、学习方法 |
| 教学准备（刀、量、工具 / 辅具、材料） | 工具、仪器 / 防护、材料 |
| 教学实施 | 高压安全检查、操作步骤、过程记录、检测记录 |
| 小结三项 | 学习收获、现场高压安全、设备车辆维护与场地卫生 |
| 教学反思 | 实训反思 |
| — | 增加班级、姓名、学号、工位、教师评价与签名栏 |

## 使用方法

1. 用浏览器打开 `index.html`，或按下方 Docker 部署后访问。
2. 在表格中直接填写，内容会自动保存在本机浏览器中。
3. 点击 **打印 / 导出 PDF**。
4. 在打印对话框中：
   - 目标打印机：`另存为 PDF`
   - 纸张：`A3`
   - 方向：`横向`
   - 边距：`无`
   - 勾选 `背景图形`，以保留绿色表格线

也可点击「填写示例」查看一份动力电池包拆装与绝缘检测样例，或「清空」后打印空白表手写。

## Docker 部署

需要本机已安装 Docker 和 Docker Compose。

```bash
docker compose up -d --build
```

浏览器打开 http://localhost:5174 即可填写、打印 PDF。

常用命令：

```bash
docker compose ps
docker compose logs -f
docker compose down
```

默认把容器 80 端口映射到本机 **5174**。若要改端口，编辑 `docker-compose.yml` 中的 `"5174:80"`。
