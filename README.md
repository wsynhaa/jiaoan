# 学生实训记录表（A3）

将教师教案表改为**学生实训记录表**，并做成一张 **A3 横向** 可填写页面，支持打印为 PDF。

## 对照说明

| 教师教案 | 学生实训记录表 |
| --- | --- |
| 课题 | 实训课题 |
| 教学目标 | 实训目标 |
| 教学重点 / 难点 | 实训重点 / 实训难点 |
| 教学方法、学生学法 | 实训方法、学习方法 |
| 教学准备（刀、量、工具 / 辅具、材料） | 实训准备（保留原分类） |
| 教学实施 | 实训实施（安全检查、操作步骤、过程记录、质量检测） |
| 小结三项 | 实训效果与学习收获、现场管理与安全、设备保养与场地卫生 |
| 教学反思 | 实训反思 |
| — | 增加班级、姓名、学号、工位、教师评价与签名栏 |

## 使用方法

1. 用浏览器打开 `index.html`。
2. 在表格中直接填写，内容会自动保存在本机浏览器中。
3. 点击 **打印 / 导出 PDF**。
4. 在打印对话框中：
   - 目标打印机：`另存为 PDF`
   - 纸张：`A3`
   - 方向：`横向`
   - 边距：`无`
   - 勾选 `背景图形`，以保留绿色表格线

也可点击「填写示例」查看一份车工实训样例，或「清空」后打印空白表手写。

## Docker 部署

需要本机已安装 Docker 和 Docker Compose。

```bash
docker compose up -d --build
```

浏览器打开 http://localhost:8080 即可填写、打印 PDF。

常用命令：

```bash
docker compose ps
docker compose logs -f
docker compose down
```

默认把容器 80 端口映射到本机 **8080**。若要改端口，编辑 `docker-compose.yml` 中的 `"8080:80"`。
